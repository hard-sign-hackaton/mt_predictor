# Действия оператора: следующий этап

Карточка инцидента пока содержит только три демонстрационные кнопки без записи данных.

Для рабочего контура потребуется таблица `operator_actions` со связью на `incidents.id`, типом действия, исполнителем, комментарием, временем создания и обновления, а также статусом выполнения. API должен поддерживать создание действия, получение списка по инциденту и изменение статуса с аудитом автора и времени. До появления авторизации исполнитель не должен задаваться frontend самостоятельно.
